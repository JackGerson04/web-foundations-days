About QuickNotes

QuickNotes is a simple note-taking concept for recording ideas, tasks, and reminders in one place. It is designed to help users organise information quickly and return to important details when they need them.

How to use QuickNotes

  1. Open QuickNotes and decide what information you need to remember.
  2. Write a short, clear note using a title or keywords where helpful.
  3. Review your notes regularly and update or remove information that is no longer useful.

Features

  • Quick capture of ideas, tasks, and reminders.
  • Simple layout that is easy to understand.
  • Organised information that is easy to review.
  • Keyboard shortcuts for common actions.

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
